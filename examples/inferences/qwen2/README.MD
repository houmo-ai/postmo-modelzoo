# Qwen2(通义千问2)

本示例展示如何把编译后的Qwen2模型部署到后摩鸿途芯片的设备上。

[TOC]

## 1 模型说明

本例使用的 Qwen2 实现来源于[https://huggingface.co/Qwen/Qwen2-7B-Instruct](https://huggingface.co/Qwen/Qwen2-7B-Instruct)。

目前芯片模型只能在linux环境下量化和编译，请参考houmo-modelzoo/models/llm/qwen2中的量化和编译。

## 2 快速开始

目前Qwen模型仅提供python脚本部署方式。

1. 将python目录加入PYTHONPATH环境变量

2. 设置运行库路径
    - linux环境将lib目录加入LD_LIBRARY_PATH环境变量
    - windows环境将bin目录下dll库以及houmo_drv包bin目录下的cyghm800_hal.dll拷贝到python/tcim_lite目录下

3. 获取模型文件，执行：

```bash
python3 get_model.py
```

5. 执行演示程序，执行：

```bash
python3 demo.py
```

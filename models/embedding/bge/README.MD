## 1 模型说明

本例使用的 bge-reranker 实现来源于[https://huggingface.co/BAAI/bge-reranker-v2-m3](https://huggingface.co/BAAI/bge-reranker-v2-m3)。
本例使用的 bge-m3 实现来源于[https://huggingface.co/BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3)。

## 2 快速开始

bge暂时提供已经量化好的模型。

### 2.1 获取模型和数据

通过get_model脚本下载模型，暂时仅支持芯片模型。

```bash
python3 get_model.py --type hmm
```

也可以直接下载以上所有模型和数据集（注意相同模型会覆盖，请自行保存）：

```bash
python3 get_model.py
```

## 3 参考结果

### 3.1 演示结果

```bash
对corpus编码，查询符合query的资料：
    corpus = [
        "北京有很多著名的牛肉面馆。",
        "上海是中国的金融中心。",
        "故宫是北京著名的旅游景点。",
        "兰州牛肉面是非常有名的中国美食。",
        "深圳以科技产业闻名。",
        "北京海淀区有一家西北牛肉面馆非常好吃。"
    ]

    query = "北京哪里有好吃的牛肉面"
结果:
==== 粗召回结果 (bge-m3) ====
北京海淀区有一家西北牛肉面馆非常好吃。 score:0.971890
上海是中国的金融中心。 score:0.523505
故宫是北京著名的旅游景点。 score:0.503346

==== 精排结果 (bge-reranker-v2-m3) ====
doc: 北京海淀区有一家西北牛肉面馆非常好吃。  →  score: -1.9336
doc: 故宫是北京著名的旅游景点。  →  score: -4.0898
doc: 上海是中国的金融中心。  →  score: -5.6172
```

# Qwen(通义千问)

本示例展示如何把量化后的Qwen模型编译，部署到后摩鸿途芯片的设备上。

[TOC]

## 1 模型说明

本例使用的 Qwen1.5 实现来源于[https://huggingface.co/Qwen/Qwen1.5-7B-Chat](https://huggingface.co/Qwen/Qwen1.5-7B-Chat)。

## 2 快速开始

目前Qwen模型仅提供python脚本编译方式。

### 2.1 获取模型和数据

获取模型和数据方法与其他模型相同，具体请参考houmo-modelzoo根目录下README.md文件的快速上手-获取模型和数据章节。

```bash
python3 get_model.py
```

### 2.2 编译

将量化模型编译为在芯片上运行的模型。执行脚本：

```bash
python3 build.py
```

上述命令可通过参数配置切换模式：

1. `--core`：模型使用的AI核数，可配置`2`或`4`，默认为`4`
2. `--stage`：编译过程控制，配置`build`为仅编译，配置`test`为仅推理和golden比对，配置`all`为编译+推理和golden比对，默认为`all`

### 2.3 演示

Qwen模型使用python API进行演示，同时输出性能结果。执行脚本：

```bash
python3 demo.py
```

### 2.4 一键评估

以上步骤可以通过perf.sh脚本一键执行：

```bash
bash perf.sh
```

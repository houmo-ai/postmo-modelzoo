# Qwen3(通义千问3)

本示例展示如何把Qwen3模型量化和编译，部署到后摩鸿途芯片的设备上。

[TOC]

## 1 模型说明

本例使用的模型实现来源于[https://www.modelscope.cn/models/Qwen/Qwen3-30B-A3B](https://www.modelscope.cn/models/Qwen/Qwen3-30B-A3B)。
本例只适用于xh2。

## 2 快速开始

目前Qwen3模型仅提供python脚本编译方式。芯片模型只能在linux环境下量化和编译。

### 2.1 获取模型和数据

通过get_model脚本下载模型，可通过参数选择下载原始模型、量化模型或芯片模型。

如果需要自己量化，可选择下载原始模型和wikitext2数据集，下载后的模型存放在qwen3-14b目录：

```bash
python3 get_model.py --type raw
```

如果仅查看演示结果，可选择下载芯片模型，下载后的模型存放在当前目录（注意相同模型会覆盖，请自行保存）：

```bash
python3 get_model.py --type hmm
```

### 2.2 量化

量化需要使用GPU，并在宿主机安装与CUDA12.2兼容的CUDA和驱动。启动docker时将GPU映射到docker内，并指定可用的GPU ID，显存需要达到40GB以上，空闲内存需要达到100GB以上。参考命令：

```bash
docker run -it --gpus all --pid=host -w /hmdd -v $PWD:/hmdd --shm-size 64g harbor.houmo.ai/toolchain/release:vx.y.z-ubuntu20.04-py39-x86.64 /bin/bash
```

进入docker后source环境变量，并进入`models/llm/qwen3`目录，执行ptq.py脚本。默认的prefill和decode上下文长度分别为256和8192。

```bash
source env.sh
cd models/llm/qwen3-30b-a3b
```

量化完成的模型存放在`output/$HOUMO_TARGET/hmquant`目录：

```bash
.
|-- decoder
|-- prefill
|-- quant_embedding.pt
```

### 2.3 编译

将量化模型编译为在芯片上运行的模型。执行脚本：

```bash
python3 build.py
```

编译好的模型存放在当前目录，包括2个文件：
qwen3_prefill.hmm
qwen3_decode.hmm

### 2.3 演示

Qwen2模型使用python API进行演示

1. 将编译好的模型放在当前目录，同时将对应量化模型的`quant_embedding.pt`文件放在量化模型目录下，也可通过demo中的`EMBEDDING_PATH`变量指定位置

2. 执行脚本，推理完成将输出性能结果。

```bash
python3 demo.py
```

### 2.4 一键评估

以上步骤可以通过test.sh脚本一键执行：

```bash
bash test.sh
```

- **存算一体**：计算直接在存储单元内部完成，减少了数据搬运，显著降低了延迟，提高了计算效率。

### 2. **显著降低功耗**
- **传统架构**：数据搬运消耗大量能量，尤其是在大规模数据处理中。
- **存算一体**：由于减少了数据移动，功耗大幅降低，特别适合对能耗敏感的边缘设备和物联网终端。

---

### 3. **提高能效比（Energy Efficiency）**
- 存算一体技术在处理密集型计算任务（如神经网络推理）时，能效比远高于传统CPU或GPU，适合部署在功耗受限的场景中。

---

### 4. **支持大规模并行计算**
- 存算一体架构通常基于存储器的并行特性（如SRAM、DRAM、ReRAM等），能够实现大规模并行计算，适合处理矩阵运算、神经网络等任务。

---

### 5. **适用于AI和机器学习**
- 存算一体技术特别适合处理深度学习中的矩阵乘法和卷积操作，能够显著提升AI推理和训练的效率，降低硬件成本。

---

### 6. **减少对高速缓存和内存带宽的依赖**
- 传统架构依赖高速缓存和内存带宽来支撑计算，而存算一体直接在存储器中进行计算，减少了对这些资源的依赖。

---

### 7. **适合边缘计算和物联网**
- 在边缘设备中，存算一体技术可以实现本地数据处理，减少对云端的依赖，提高实时性和隐私保护。

---

### 8. **支持新型存储器技术**
- 存算一体技术可以与新型存储器（如ReRAM、PCM、MRAM等）结合，充分发挥其非易失性、低功耗、高密度等优势。

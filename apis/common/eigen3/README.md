# Eigen 3.4.0 source subset

This directory contains the Eigen 3.4.0 headers required by `tools/llm_perf`
and `tools/common/houmo-llm-engine` for `unsupported/Eigen/CXX11/Tensor`.
Upstream repository: https://gitlab.com/libeigen/eigen

Tests, benchmarks, documentation, build and packaging files, unsupported
modules not used by Tensor, and Eigen modules not reachable from `Eigen/Core`
were removed. Original per-file copyright and license notices are retained.

See `COPYING.README`, `COPYING.MPL2`, `COPYING.APACHE`, and `COPYING.BSD` for
the applicable license information.

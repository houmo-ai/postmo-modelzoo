# yaml-cpp source subset

This directory contains the yaml-cpp 0.9.0 source files required by
`tools/llm_perf`. Upstream repository: https://github.com/jbeder/yaml-cpp

yaml-cpp is distributed under the MIT license. The original copyright and
license text are retained in `LICENSE` as required by that license.

`src/contrib/dragonbox.h` is required by yaml-cpp's floating-point formatter
and retains its upstream SPDX copyright and license notices in the file. Its
MIT license text is retained in `DRAGONBOX_LICENSE`.

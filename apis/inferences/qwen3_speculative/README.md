# Qwen3 投机解码模型运行指南

本指南介绍如何将编译好的 Qwen3 模型部署到后摩芯片设备上进行投机解码推理。

## 1. 快速开始

### 1.1 获取模型和数据

通过 `get_model.py` 脚本下载模型，可通过参数选择芯片模型。您也可以使用 `apis/converts/qwen3_speculative` 目录下的方式自行编译模型。

```bash
python3 get_model.py --type hmm
```

模型目录结构应如下所示：

```text
qwen3/
└── output/xh2/
    ├── draft/
    │   └── hmquant/
    │       ├── decoder/           # Draft 模型的 decode 文件
    │       ├── prefill/           # Draft 模型的 prefill 文件
    │       └── quant_embedding.pt # Draft 模型的量化嵌入文件
    ├── target/
    │   └── hmquant/
    │       ├── decoder/           # Target 模型的 decode 文件
    │       ├── prefill/           # Target 模型的 prefill 文件
    │       └── quant_embedding.pt # Target 模型的量化嵌入文件
    ├── qwen3-speculative-0.6b_decode_draft.hmm     # Draft 模型的解码文件
    ├── qwen3-speculative-0.6b_prefill_draft.hmm    # Draft 模型的 prefill 文件
    ├── qwen3-speculative-14b_prefill.hmm           # Target 模型的 prefill 文件
    └── qwen3-speculative-14b_verify.hmm            # verify 文件
```

### 1.2 执行模型推理

运行以下命令启动 Demo：

```bash
python demo.py --fast
```

存算一体（Compute-in-Memory，简称 CIM）技术是一种将计算单元与存储单元集成在一起的新型芯片架构，旨在解决传统冯·诺依曼架构中“存储墙”和“功耗墙”问题。它在人工智能、边缘计算、高性能计算等领域具有显著优势。以下是存算一体技术的主要优势：

### 1. **降低数据搬运能耗**
在传统架构中，数据需要在存储器（如 DRAM）和处理器（如 CPU/GPU）之间频繁搬运，这一过程消耗大量能量。而存算一体技术将计算直接嵌入存储单元中，减少了数据搬运的次数，从而显著降低能耗。

### 2. **提升计算效率**
由于计算和存储在同一位置进行，数据无需经过总线传输，减少了延迟，提高了计算效率。这对于需要大量数据处理的 AI 任务（如神经网络推理）尤为重要。

---

### 3. **降低功耗**
由于减少了数据搬运和计算过程中的冗余操作，存算一体技术在功耗方面具有明显优势，特别适合用于移动设备、物联网设备和边缘计算设备。

---

### 4. **支持高并行计算**
存算一体架构通常采用并行计算方式，可以同时对多个存储单元中的数据进行计算，从而实现高吞吐量和高并行性，适用于大规模并行计算任务。

---

### 5. **适合 AI 与神经网络计算**
存算一体技术特别适合用于深度学习、神经网络等计算密集型任务。例如，使用存算一体芯片可以高效地执行矩阵乘法、卷积等操作，从而提升 AI 模型的推理速度。

---

### 6. **提升系统整体性能**
通过减少数据搬运和计算延迟，存算一体技术可以提升整个系统的性能，使得设备在处理复杂任务时更加高效。

---

### 7. **支持低功耗边缘计算**
在边缘计算场景中，设备通常需要在有限的功耗下完成复杂的计算任务。存算一体技术可以有效降低功耗，使得边缘设备能够更长时间地运行 AI 模型。

---

### 8. **可扩展性强**
存算一体架构可以根据需要进行扩展，适用于不同规模的计算任务，从嵌入式设备到数据中心都可以应用。

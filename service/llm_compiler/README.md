# 自动量化编译大模型服务

通过本服务，可实现自动编译大模型的功能，支持指定量化模型进行编译，也支持使用默认参数量化及编译。

支持的大模型及规格见：supported_models.json

## 环境依赖

依赖的python三方库已在requirements.txt中列出。

在当前目录 `service/llm_compiler/` 下执行 `pip3 install -r requirements.txt` 即可安装所有依赖的库。

## 使用方法

在当前目录 `service/llm_compiler/` 下执行python脚本 `compile_llms.py`，并传入编译模型所需参数，即可进行模型编译。

### 参数说明

- `-name`,  `--model_name`：必需，模型名称，例如：qwen3
- `-size`,  `--model_size`：必需，模型规格，例如：8b、14b
- `-v`,  `--version`：必需，大道软件版本号，例如：2.4.2, 0.3.0
- `-t`, `--target`：xh1 or xh2，默认：xh2
- `-qm`,  `--quant_model_path`：量化模型Jfrog路径，xh1必需指定量化模型
- `-pl`, `--prefill_length`：prefill长度，默认256
- `-cl`, `--context_length`：上下文长度，默认2048
- `-b`, `--batch`：batch数量，默认1
- `-dn`,  `--device_num`：device数量，默认1
- `-cn`, `--core_num`：core数量，默认1
- `-up`,  `--upload`：上传编译后模型至Jfrog AutoGeneratedModels仓库, 并添加模型信息至 published_models.csv
- `-r`, `--result_dir`：存储编译模型产物的路径，默认为当前路径

*注：模型名称和模型规格见文件 supported_models.json，不支持自定义名称或规格。*

### 示例

1. (xh2-v0.3.0) 使用指定Jfrog量化模型编译deepseek-r1-qwen3 8b 4k上下文: `python3 compile_llms.py -name deepseek-r1-qwen3 -size 8b -v 0.3.0 -t xh2 -cl 4096 -qm http://10.10.1.53:8082/artifactory/AutoGeneratedModels/deepseek-r1-qwen3/20250901/hmquant_xh2_deepseek-r1-qwen3_8b_256_4k_1756697441.142978.zip -up -r /data/models/deepseek-r1-qwen3-8b`

2. (xh2-v0.3.0) 使用指定Jfrog量化模型编译qwen3 8b 8k上下文: `python3 compile_llms.py -name qwen3 -size 8b -v 0.3.0 -t xh2 -cl 8196 -qm http://10.10.1.53:8082/artifactory/AutoGeneratedModels/qwen3/20250901/hmquant_xh2_qwen3_14b_256_4k_1756737932.706066.zip -up -r /data/models/qwen3-8b`

3. (xh2-v0.3.0) 不指定量化模型，编译qwen3 14b 2k上下文: `python3 compile_llms.py -name qwen3 -size 14b -v 0.3.0 -t xh2 -cl 2048 -up -r /data/models/qwen3-8b`

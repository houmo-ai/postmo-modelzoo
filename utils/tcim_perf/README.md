|tcim_perf.cc|主文件，实现TCIM模型推理流程|

## 2.流程说明

程序按以下流程进行：

1. 解析输入参数
2. 创建推理Module
3. 准备输入数据和输入输出内存
4. warm up
5. 创建线程，每个线程绑定一个推理Module
6. 根据设定的次数执行输入数据->推理->获取结果循环，统计每次推理总时延和最大时延
7. 获取执行总时间，计算平均执行时间和吞吐量

## 3.快速开始

### 3.1 环境准备

进入modelzoo根目录，先检查 `env.sh` 里的环境变量，根据模型实际路径修改 `env.sh` 内的 `MODEL_PATH`, 并且执行以下命令：

```bash
source env.sh
```

设置完成后进入程序目录：

```bash
cd utils/tcim_perf/
```

### 3.2 一键运行

执行build脚本编译

```bash
./build.sh
```

执行run脚本运行，可通过命令行参数修改模型路径、执行次数、线程数和stream数等，目前只支持线程数与stream数相同，即每个推理module使用1个stream

```bash
./run.sh
```

结果：

```bash

Inference max latency = *ms
Inference Throughput total cost = *ms
Inference Throughput average cost = *ms
Inference Throughput(QPS): *
```

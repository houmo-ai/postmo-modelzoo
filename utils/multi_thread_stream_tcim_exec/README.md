本代码用于在鸿途H30芯片的设备上测试多线程stream推理。

## 1.文件说明

|文件名|说明|
|main.cc|主文件，实现多线程stream推理流程|
|get_time.h|时间统计类|

## 2.流程说明

程序按以下流程进行：

1. 解析输入参数
2. 创建Stream
3. 创建推理Module并绑定到Stream
4. 创建线程，每个线程绑定一个推理Module
5. 根据设定的次数执行输入数据->推理->获取结果循环，统计每个线程执行时间
6. 获取执行总时间，计算平均执行时间和吞吐率

## 3.快速开始

### 3.1 环境准备

进入modelzoo根目录，先检查 `env.sh` 里的环境变量，根据模型实际路径修改 `env.sh` 内的 `MODEL_PATH`, 并且执行以下命令：

```bash
source env.sh
```

设置完成后进入程序目录：

```bash
cd utils/multi_thread_stream_tcim_exec/
```

### 3.2 一键运行

执行build脚本编译

```bash
./build.sh
```

执行run脚本运行，可通过命令行参数修改模型路径、执行次数、线程数和stream数等，目前只支持线程数与stream数相同，即每个推理module使用1个stream

```bash
./run.sh
```

结果：

```bash
Inference time cost total = *ms
Inference time cost per frame = *ms
Average Throughput(QPS): *fps
```
